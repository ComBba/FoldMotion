# FoldMotion 개인정보 처리방침 (초안)

시행일: 2026-09-16  
운영: FoldMotion (`com.foldmotion.app`)

## 수집하는 정보

FoldMotion은 계정을 만들지 않으며, 이름·이메일·위치·광고 ID·연락처를 수집하지 않습니다.

앱은 기기의 힌지 각도 센서 값을 **기기 안에서만** 읽어 시각 효과와 햅틱을 계산합니다. 이 값은 서버로 전송되지 않습니다.

설정(효과 켜짐, 스타일, 강도, 햅틱)은 기기 로컬 `SharedPreferences`에만 저장됩니다.

## 권한

- 다른 앱 위에 표시: 접힘 효과 Overlay
- 알림: 효과가 켜져 있음을 알리고 끄기
- 진동: 사용자가 햅틱을 켠 경우
- 포그라운드 서비스: 앱을 닫아도 효과를 유지

## 제3자

광고 SDK, 분석 SDK, 크래시 수집기를 포함하지 않습니다.
